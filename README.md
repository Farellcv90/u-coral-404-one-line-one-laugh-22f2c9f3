A single hilarious line for make.fun's "One Line, One Laugh" bounty: a man asks his
doctor for something to help him sleep — and gets prescribed his own wedding video.

> I asked my doctor for something to help me sleep. He prescribed my own wedding video.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt` (84 characters, no trailing newline).

## How it works

`main.py` is pure Python stdlib — no network, no secrets. It validates the entry
(1–200 characters, a single line, not only whitespace) and writes it verbatim to
`/output/entry.txt`.
